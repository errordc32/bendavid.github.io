## Overview

Library staff had no easy way to track patron items. I built an automated system to do it.

## What I did

- **Designed** an automated tracking system for patron items.
- Wrote an **Arduino IoT library** that sends status and user data to the team through the **Slack API**.
- **Programmed** an automated database-handling system connecting **Google Workspace** and **Ex Libris**.
